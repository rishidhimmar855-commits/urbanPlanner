# UrbanVision

Government smart-city planning UI around a 3D city engine.

## Run

```bash
cd city-sandbox
npm install
npm run dev
```

## Flow

1. **Login** → Overview dashboard  
2. **Overview** — impact stats + projects + New project  
3. **3D Visualize** — map + amenities + setup  
4. **Reports** — preview analytics and **download** individual reports, summary, or full evidence pack  

## Downloads (Reports)

- **Download** on each report card → JSON for that report  
- **Download summary** → plain-text planning summary  
- **Download all reports** → full UrbanVision evidence pack (JSON)
